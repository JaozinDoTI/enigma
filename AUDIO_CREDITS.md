# Créditos de áudio

O sistema sonoro atual não utiliza arquivos ou amostras de terceiros.

Todos os sons são sintetizados localmente com a Web Audio API: osciladores, ruído filtrado, impulsos, hum elétrico, static, relés, Morse e texturas ambientais.

| Recurso | Origem | Licença | Uso |
| --- | --- | --- | --- |
| Soundscape procedural | Código original do projeto | Mesmo licenciamento do projeto | Ambientes, receptor, interface e narrativa |
| Interações físicas procedurais | Código original do projeto | Mesmo licenciamento do projeto | Papel, madeira, dispositivos, encaixes, contatos e quedas curtas |
| Mecanismo de arquivo procedural | Código original do projeto | Mesmo licenciamento do projeto | Relay, busca de disco, canal de dados, falha de checksum e fechamento |
| Investigação procedural | Código original do projeto | Mesmo licenciamento do projeto | Contato de evidência, traçado elétrico, conexão e rejeição de circuito |

As variações são produzidas em tempo de execução por seleção de perfil, pequenas mudanças de frequência, filtragem, panorama, envelopes e ruído gerado localmente. Nenhum áudio de terceiros ou hotlink foi incorporado nesta etapa.
