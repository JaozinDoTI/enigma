# Placeholders de QR

Os QRs definitivos são gerados localmente pela página `dev/physical-kit.html` depois que a URL de publicação for definida.

- `QR_01_DESK` → `http://SEU-ENDERECO/node.html?node=desk`
- `QR_02_YARD` → `http://SEU-ENDERECO/node.html?node=yard`
- `QR_03_BOOKS` → `http://SEU-ENDERECO/node.html?node=books`

A página usa correção de erro alta e margem de leitura. Teste os cartões impressos antes de esconder.
