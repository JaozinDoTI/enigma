# Fontes reais das estantes

Os bytes das duas fotografias anexadas na conversa não foram disponibilizados ao workspace. Para ativar o BOOKSCAN sem alterar código, coloque cópias dos dois arquivos originais nesta pasta usando a extensão real recebida (`.jpg`, `.jpeg`, `.png` ou `.webp`):

- `shelf-source-01.<ext>` — fotografia da estante superior, com a coleção “É Assim que…”.
- `shelf-source-02.<ext>` — fotografia da segunda estante, com as coleções Julia Quinn e Lisa Kleypas.

Não substitua os originais. O pipeline local lê essas duas fontes e deve gerar:

- `shelf-cam-01.jpg`
- `shelf-cam-02.jpg`
- `shelf-crop-ending-beginning.jpg`
- `shelf-recovered-01.jpg`

Enquanto os derivados não existirem, o jogo mostra explicitamente “CAPTURA AUSENTE”; ele não usa ilustração genérica como substituta silenciosa.
